## ❓ Frequently Asked Questions

### What is this toolkit?

It is a standalone desktop organization and customization companion for managing wallpaper collections and profiles.

### Can I organize animated wallpapers?

Yes. Animated Wallpaper Library lets you categorize and manage animated backgrounds.

### Does it support 4K wallpapers?

Yes. You can organize Full HD, 1440p, 4K, ultrawide, and vertical-display collections.

### Can I create multi-monitor profiles?

Yes. Separate wallpaper layouts can be stored for multiple displays.

### Can I organize Android wallpapers?

Yes. Mobile wallpapers can be stored in separate Android-oriented collections.

### Is this Wallpaper Engine itself?

No. Wallpaper Engine is a separate Steam application. This repository is a wallpaper-management and desktop-customization toolkit.
